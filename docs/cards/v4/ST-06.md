Create a <=3-minute reel from real logged race events and recorded footage, with every pass and incident auditable.

## Build
1. Inspect event schema and units. Convert event times to session seconds once; reject invalid/nonfinite values with reason.
2. Create ordered start, each pass, each incident, last-lap, finish segments. Pass/incident intervals are [t-3s,t+2s], clipped to capture bounds; merge overlaps while retaining all event IDs.
3. Map session to clip time via sidecar videoStart/lap offsets; honor rotation:180 through ffmpeg autorotate. Missing/truncated coverage is explicit failure, never substitute unrelated footage.
4. Cut/concatenate with local ffmpeg. If all required segments exceed 180s, return overflow and event manifest; never silently omit events. Only real in-sim images in product.
5. Add Studio.RaceHighlights and status JSON as new code using typed event data, not parsed display strings. Offline fixture tests only. C# 5; no iRacing writes.

At least 6 event ID assertions plus checks for start/last-lap/finish, clipping/overlap, sidecar time conversion, autorotation, <=180s or explicit overflow, missing footage failure. Every logged pass/incident occurs exactly once in manifest; mutation dropping one must fail. Peter fails if event missing or reel >3 min. Compile -NoDeploy.
