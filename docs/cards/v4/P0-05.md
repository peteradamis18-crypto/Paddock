## Build
1. Create new `dash\src\gpsmap.cs` (C# 5). Read only Peter's own `.ibt` files, never iRacing config files.
2. Read old `.ibt` telemetry only through the existing analysis reader. Select a complete clean lap (valid lap >15 s, no pit/off-track flags); never read the newest file while a session is active. Convert GPS to local metres relative to the first fix: `x=(lon-lon0)*cos(lat0*pi/180)*111320`, `y=(lat-lat0)*110540`. Keep points ordered by `LapDistPct`; reject nonfinite fixes, duplicate pct and gaps over 5 percentage points. Retain `Alt` in metres in JSON only.
3. Fit corresponding resampled points to real library geometry with uniform scale, rotation and translation (least-squares 2D fit); report `meanErrorM`, `maxErrorM`, point count and source file. Do not fit by matching arbitrary nearest segments.
4. Extend `/trackmap` at `irdash.cs:724` and `TrackMaps` at `irdash.cs:883`. Keep established library geometry as the display when present and expose the measured GPS line; where no library geometry exists, render the GPS line only if a full telemetry fixture exists. Never claim Sonoma coverage without that fixture.
5. In `dash\www\v2\map.js`, add the GPS projection to the existing flat map coordinate system. `Alt` is retained but must not affect screen x/y; no hills or synthetic track art.
6. Add `gpsmap.cs` to the `$src` list in `dash\build.ps1`.
7. Create new `tests\gpsmap-test.ps1`; dot-source `tests\guard.ps1` and call `Assert-RigFree` before each section. Assert Road Atlanta mean fit <=5 m and max <=15 m, each matched Lovely apex <=20 m from the GPS line, Sonoma map present when a complete lap fixture exists, Alt remains metadata only, and screenshot count equals available map fixtures.
8. Compile only: `powershell -ExecutionPolicy Bypass -File dash\build.ps1 -NoDeploy`. Deploy only when `irdeck-cli.exe state` shows `sim=False`; exit 2 = stop.
