## Build
1. Offline mock first. Before every live section and interaction dot-source tests/guard.ps1 and call Assert-RigFree -NeedAway. Abort if unsafe.
2. Add Studio.FilmShotList using actual ST-02 schema. Confirm loaded replay identity matches source before sending commands. Reuse recorder rolling-segment/cut path; do not assume a named-take API.
3. Do not seek separately for every cue. Play continuously; at cue time send validated group/camera using existing packing, preserve CamCameraState & 0x1FC and set 0x08. Slow only the tagged worst corner, then restore speed 1. Log actual cue error in ms.
4. Cut lap start-1s through end+1s, max 150 MB. If existing recorder settings cannot meet limit, fail with measured size rather than silently changing quality. ffprobe must confirm 1920x1080 upright/no rotation side data.
5. Extend new tests/studio-test.ps1 with offline and separate live-away sections. C# 5, no iRacing file writes, real assets only.

## Gate
At least 8 offline numeric checks: cue order, command packing, UI-bit preservation, speed reset, no per-cue seeking, wrong-session refusal, size limit and clip bounds. Live away: >=4 cuts each within 500 ms; file <150 MB; duration lap ±1s; ffprobe upright 1920x1080/no rotation; SDK snapshot UI hidden. Every assertion ok/FAIL; off-plan, upside-down or menu-visible video fails Peter's journey. Build dash/build.ps1 -NoDeploy only; live gate pending without away window.
