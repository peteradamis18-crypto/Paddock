## Build
1. Before the race, prepare a manual observation sheet and verify in source the exact TV JSON fields and each displayed conversion. No code/test hook may inject frames during a live race.
2. Check `irdeck-cli.exe state` before any setup. When the race begins, do not send requests that start apps, click, focus windows, show popups, or consume the sim's control channel. Observe existing display and iRacing's already-visible standings only. Never read newest `.ibt` during the session.
3. At three naturally occurring moments spanning at least two laps, record timestamp/lap, displayed overall and class positions, leading gap/interval as shown by the existing UI, and relative-map location for Peter plus one nearby car. Compare only values that iRacing visibly exposes at that moment; do not assert exact equality with unverified `CarIdxF2Time`/`CarIdxEstTime` (these were not confirmed in `field.cs`). For map, compare track segment and ordering, not pixel accuracy from a camera view.
4. FPS: use an existing same car/track/session baseline in Performance page if available. No app switch or interaction while driving. If no matched baseline exists, record “not comparable”; do not claim unchanged FPS from an unmatched average.
5. After session end, with rig free, run offline `tests\tv-test.ps1` (if present) and `dash\build.ps1 -NoDeploy`. Do not alter TV logic unless a reproducible discrepancy is isolated and separately reported.
6. Write observed numbers and any mismatch in `docs\tasks\log\T-07.md`; report remains pending when a race/visible comparison was unavailable.

## Gate
At three moments over >=2 laps: record 3/3 displayed position comparisons, 3/3 displayed gap/interval comparisons where same basis is visible (tolerance 0.1 s), and 3/3 map segment/order comparisons matching the relative. Matched Performance baseline only: record both FPS and require difference <= normal run-to-run range shown by that baseline; otherwise mark FPS `not comparable`, which does not pass the full gate. No interaction/control messages during race. Offline TV test 0 FAIL and compile `dash\build.ps1 -NoDeploy` exit 0 after the race. Peter fails the gate if any displayed position or comparable gap differs beyond tolerance or any dot is on the wrong track segment.
