## Build
1. Confirm the T-01 map identity fields and P0-05 real map endpoint/model. Track map points are keyed by lap fraction 0..1. Do not use a drawing, SVG stand-in, generic silhouette, or made-up GPS.
2. Extend `TrackMap` integration in `tv.js` (existing C-22 file) or the existing TV module after checking its ownership. The map area in 3d is nominally 1300x700 CSS px; scale responsively within the existing panel. Use existing map projection and fit behavior; all cars and outline must share the identical projection transform.
3. For each valid car `pct` in [0,1], project that fraction onto the real outline and draw a point in `classColor`. Player dot is gold with verified car number; leader gets a thin ring; every car in each T-01 battle pair gets a ring. Do not label every car. If outline is unavailable, use the established straight lap bar; never display a fabricated circuit.
4. Reuse `Corners.draw` for outline annotations and pass a real track data object. Verify the supported option names in the implementation; `ticks`, `pit`, `names`, and `credit` options exist. Keep start/finish, known sector ticks and pit lane; remove corner names/credit only if the wireframe requires it and keep required attribution where data requires it. No 3D projection/elevation.
5. Read one `/tv/data` response per 100 ms tick, update positions from it, cap canvas drawing at 30 fps. Handle invalid pct, pit values, missing map and missing battle list without exceptions.
6. Test 20 car positions at several fractions including 0.0/0.99 and wraparound; assert projected centers within 2 px of expected points, leader/player/battle rings, class colors, and no non-real outline. Assert draw count <=60 in 2 seconds.
