## What to build
1. **`sdkreader.cs`**: move the `Sdk` class out of irdash.cs as it is (same names, so nothing else changes), then: parse
   the session YAML ONCE per `SessionVersion` on the reader thread into a `Session` object the server can use
   (`Sdk.Session`: Type, Num, Laps, TimeSec, IncidentLimit (WeekendInfo.WeekendOptions.IncidentLimit, "unlimited" → 0),
   Multiclass, `Drivers[]` by CarIdx: Num, ShortName (the surname of UserName, iRacing's duplicate digits dropped; CarScreenNameShort is the CAR's name), ClassId,
   ClassShort, ClassColor, IsPaceCar, IsSpectator); `StateBuilder.SessionPart` keeps its JSON but is fed from this parse
   (no second YAML parse; the parse runs right after the frame is published, so the session follows one frame late). `ReadYaml` already ran only when the version changed (W2-1 measured: 0.04 ms to read,
   0.5 ms to parse the 52 KB 12 Nov YAML).
2. **The `race` channel set**: `/stream?set=race` (and `vars=` as before) = exactly these 28 and nothing else (a channel the sim lacks is sent as null), 15 Hz:
   `CarIdxPosition, CarIdxClassPosition, CarIdxF2Time, CarIdxLapDistPct, CarIdxEstTime, CarIdxOnPitRoad, CarIdxClass,
   CarIdxLap, Lap, LapCompleted, SessionLapsRemainEx, SessionTimeRemain, SessionTime, PlayerCarMyIncidentCount,
   SessionFlags, FuelLevel, FuelUsePerHour, LapLastLapTime, LapBestLapTime, LapDeltaToBestLap, LapDeltaToBestLap_OK,
   OnPitRoad, PlayerCarIdx, IsOnTrack, IsReplayPlaying, SessionNum, DisplayUnits, EngineWarnings` (the last four from the race page review). A test counts the keys on the wire.
3. **`fuel.cs`** (pure, `static class Fuel`, fed one sample per frame at ≤ 15 Hz, state read at ≤ 4 Hz; PLAN "Fuel maths"):
   burn = average of the last 3 clean laps (5 for the long view: expose both); a lap is clean when it was green all
   the way (SessionFlags never caution/yellow during it), no pit in/out (OnPitRoad false throughout), no off-track
   (PlayerTrackSurface stays on track: add it to the sample, not to the wire), and counted by iRacing where the live
   judge knows (W0-6; else the clean rule alone); caution laps excluded; after a pit stop (fuel level rises) the burn is kept but
   marked `stale: true` until 3 new clean laps. Laps to go (`toGo`) counts the lap he is on: `SessionLapsRemainEx` in a lap race (it counts the current lap: 13 Nov qualifying file), else ceil(`SessionTimeRemain` / average clean lap + LapDistPct) + 1; the average lap is the clean laps' (never a pit or caution lap), the session's DriverCarEstLapTime before the first. The distance is toGo − LapDistPct.
   Fuel to end (`toEnd`, litres, positive = still to add) = distance × burn × 1.05 − level ("+1 lap kept back" is the 5 %, not a setting); `spare` = lapsOfFuel − distance (plain laps), `margin` = 0.05 × distance, state `short` when spare < margin, `save` when within one lap (states: measuring | ok | short | save). Before 3 clean laps:
   `state: "measuring", measured: n`. Pit window for the NEXT stop (against the stops still needed, `stops`): one cell per lap to go, PLAN's colours: white = can't finish (no lap is green),
   red = short (the tank runs dry by that line if you have not stopped), orange = too early (from there even full tanks at the stops still needed do not reach the end),
   green = window open (a stop there reaches the end, or the next needed stop, with the margin). `save` = litres per lap to save to
   gain one lap when within one lap of making it, else null. Units: litres (the sim's; the page converts for display).
4. **The `race` state part** (`StateBuilder.Add("race", 2000, 250, …)`): `null` unless RigState.Driving (IsOnTrack on a fresh frame) and no IsReplayPlaying; the garage, spectating and a replay give null:
   ```
   {"on":true,"type":"Race","multiclass":false,"me":{"idx":8,"num":"9","name":"Adamis","classId":0,"classColor":"#ffda59"},
    "pos":4,"of":22,"classPos":2,"classOf":12,"lapNum":43,"laps":52,"toGo":9,"timeLeft":null,"clock":3753.2,
    "inc":{"n":4,"limit":17},"flags":{"caution":false,"green":true,"raw":268435456},
    "pit":{"onRoad":false,"limiter":false,"loss":null,"rejoin":null},"units":"metric",
    "fuel":{"state":"ok","measured":3,"stale":false,"level":22.4,"burn":2.31,"burnLong":2.28,"lapsOfFuel":9.7,"toEnd":-0.6,"spare":0.7,"margin":0.45,"save":null,"stops":0,
            "window":["green","green","green","green","green","green","green","green","green"]},
    "lap":{"last":93.832,"best":93.412,"lastIsBest":true,"delta":-0.21,"deltaOk":true}}
   ```
   `lapNum` is the lap number and `lap` the lap times object (each once: the lead's call, 2026-11-14). `of`/`classOf` count the cars in the world (CarIdxPosition > 0 or LapDistPct >= 0), per class for classOf. `pit.limiter` = EngineWarnings bit 0x10; `units` from DisplayUnits (1 = metric; missing = metric), the page converts litres. No `lap.optimal` (no sector part until wave 4).
   `pit.loss`/`pit.rejoin` stay null here (W2-3 fills them through a hook `Func<string, double?> Fuel.PitLossFor` the lead
   wires at merge: track name → seconds, null = not measured). `toGo` is the Fuel module's value. Standings order is
   NOT here: the page sorts the stream's `CarIdxClassPosition` and reads names from the `session` part.
5. Request budget (W0-5 tests): no new poller; the part is made on the frame thread's 4 Hz tick like the others.
