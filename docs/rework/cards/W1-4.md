## The page (the 1920×1080 dashboard monitor above the race screens; seat distance: nothing under 24 px, PLAN rule 4; one `design.css`, no new hex and no new font size, rule 5: the type-scale tokens win over the pixel sizes named below)
**Top (y 40):** title RACES, the storage line "412 GB used · 280 GB free · about 38 more races" with a thin bar
(`storage` from `/api/library`), "14 GB in trash · EMPTY NOW" appended only when `trashGb ≥ 1`, and the tabs
RACES · PRACTICE & QUALIFYING · ALL in one row (32 px). When `lowSpace`: one gold key under the line, "Free up space:
delete the N oldest shared races (X GB)" (`racefree`); hidden when no race is shared ("Nothing shared yet to free").
**Cards:** grid, 3 per row, 600×300: the thumbnail (`/api/library/thumb?id=&w=600`; a dark card with the track name
while `thumb` is false), date (`Fmt.whenRel`: Today / Yesterday / Wed 6 Nov · 11:28, 26 px gold), track (40 px), the
facts line "Toyota GR86 · 21 min · 10 laps · best 1:33.832 · 1.1 GB" (26 px; `best` 0 → "no clean lap"), **one state
line** (32 px) from `state.kind`: none → "Not shared" · queued → "Waiting to share" · sharing → "Sharing 41%" ·
shared private → "On YouTube (private)" · shared public → "On YouTube" · failed → the `error` text · signin → "Sign in to
YouTube" (the whole line is the key: `ytsignin`) · offline → "No internet, waiting"; a "Kept" tag when `kept`. One
gold **OPEN** (64 px high) and a tick box (56 px) top-left. Newest first; the RACES tab shows `isRace` only.
**Select mode:** ticking any card shows the bottom bar (full width, 120 px): **SHARE TO YOUTUBE (3)**, **DELETE (3)**,
**CANCEL**; SHIFT-click ticks a range; a **SELECT ALL SHARED** key (for freeing space). The bar's count follows the ticks.
**OPEN:** a full-screen card over the grid: the thumbnail big, the facts, five keys in one row (72 px): **WATCH**
(`racewatch`, Windows' player on the middle screen, from the start — jumping to a moment comes with Paddock's own
player in W1-6), **SHARE TO YOUTUBE**, **TALK OVER IT** (greyed, "Comes with the commentary update" until W1-6),
**REVIEW** (opens the REVIEW door for this drive: today `sessions.html` for that session; say in the report what you
linked), **DELETE**. Under them the `markers` as a timeline (start, incidents, pits, best lap, finish) with labels, and,
when shared, the YouTube link with a **COPY LINK** key (`navigator.clipboard`, fallback: a selectable field). Esc or
CLOSE returns to the grid.
**Delete:** `racetrash` with the ticked ids (or the open card's); the cards leave at once and a toast "Deleted 3 races ·
UNDO" stays 8 s (UNDO → `raceundo a=<batch>`); no "are you sure", no second press. EMPTY NOW → `raceempty`.
**States of the page:** list · empty ("No races yet. Every race longer than 5 minutes lands here by itself.") · select
mode · open card · deleted toast · dashboard offline (`data.rig.online` false: one banner, nothing else changes) ·
driving (`data.rig.driving`: the page shows "Back after your drive", no keys) · sign-in needed (a banner across the top
with one key "SIGN IN TO YOUTUBE" when `youtube.signedIn` is false and any race is ticked or opened for sharing).
**Settings on the page (small, in the header's right corner, grey):** "Uploads are private · MAKE PUBLIC" (one press
toggles `ytprivacy`), and the title template as a list of five example titles rendered with the latest race's facts —
Peter picks by pressing one (`yttemplate a=n`), never types (PLAN §4.3 Title templates).

## Server glue (`dash\src\library.cs`; the only server file you touch)
- `raceshare a=id|id|id` (GuardedDo: it runs ffmpeg and a long upload, never during a session): for each id, in one
  `Jobs.Run("share " + id, …, whenFree)`: `Cuts.Plan(sidecar, sec)` → `Cuts.Title(template, facts)` /
  `Cuts.Description` → `Cuts.Run(ffmpeg, ffprobe, mp4, vault\cuts\, plan)` → `YouTube.Enqueue(id, cut, title, desc,
  privacy, thumb600)`. The race's state is `queued` from the press (keep a small `Library.pendingShare` set the
  `ShareState` hook consults before W1-2's record exists). A cut file is deleted once its upload is `shared`
  (the tidy routine). Answer: "Sharing 3 races" / "Already on YouTube" / "Sign in to YouTube first".
- `ytsignin`, `ytprivacy a=private|public`, `yttemplate a=1..5` → `YouTube.SignIn()` / `SetPrivacy` / `SetTemplate`
  (`ytsignin` is GuardedDo: it opens a browser). Check the lead's merge already has `Library.ShareState = YouTube.StateJson;
  Library.YouTubeJson = YouTube.Json;` in irdash.cs's start-up; if not, add it and say so.
- `Series` for the title: `Facts.Series` from the session's `official` match when one exists (`Official`/`SessMatch`
  know Peter's registered series), else empty; `Finish`/`Start` from the sidecar when it has them, else 0. Say what you
  could fill.
