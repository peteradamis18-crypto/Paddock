## What to build (`dash\src\youtube.cs`, static class `YouTube`)
**Files** (all under `dash\yt\`, created on demand): `client.json` (Peter's: read `installed.client_id`,
`installed.client_secret`; missing → state `signin` with the message "Set up YouTube first: docs\YOUTUBE-SETUP.md" —
the page shows it as one key), `token.bin` (DPAPI `ProtectedData.Protect(…, DataProtectionScope.CurrentUser)` of a
small JSON: refresh token, access token, expiry; written temp + move), `session.json` (one upload in flight: race id,
file, size, session URL, bytes sent, title, privacy, started), `uploads.json` (per race id: videoId, url, privacy,
kind, pct, error, startedMs, doneMs; this is the "never twice" record and the page's state).

**Sign-in** `YouTube.SignIn()` (called by the `ytsignin` command W1-4 wires; it opens a browser on Peter's screens, so
it is GuardedDo — list it in `rigstate.cs`'s `GuardedDo` only if the lead has not; say so in the report): an
`HttpListener` on `http://127.0.0.1:<free port>/`, PKCE S256 (32 random bytes → base64url verifier, SHA-256 challenge),
`scope=https://www.googleapis.com/auth/youtube.upload`, `access_type=offline`, `prompt=consent`, a random `state`;
open the URL with `Process.Start`; the one request back carries `code` (check `state`); exchange at the token URL
(`client_secret` goes in the POST body, never a query string); answer the browser with one plain page "Paddock is
signed in to YouTube. You can close this tab."; save `token.bin`; stop listening (also after 5 minutes with nothing).
Refresh with the refresh token when the access token is within 60 s of expiry. `invalid_grant` (revoked / dead) →
delete `token.bin`, every queued race shows kind `signin`, message "Sign in to YouTube again".

**Upload** `YouTube.Enqueue(string raceId, string file, string title, string description, string privacy, string thumbJpg)`
→ writes `uploads.json` kind `queued` and returns false with "Already on YouTube" when that race id is `shared` or
`sharing` (never twice; a `failed` one may be queued again). The work itself is `Jobs.Run("youtube upload", …, whenFree)`
(so it never runs while a session is on, and the worker already runs BelowNormal): resumable protocol
(`POST …/upload/youtube/v3/videos?uploadType=resumable&part=snippet,status` with
`{"snippet":{"title","description","categoryId":"20"},"status":{"privacyStatus":privacy,"selfDeclaredMadeForKids":false}}`,
`X-Upload-Content-Length/Type: video/mp4`; the `Location` is the session URL, saved to `session.json` before the first
byte), then `PUT` the file in 8 MiB chunks with `Content-Range: bytes a-b/total`; `308` → read `Range`, continue from the
next byte; `pct` updated in `uploads.json` after every chunk (that is the "Sharing 41%" on the card and the deck); a
`Jobs.ShouldYield` between chunks (a session started) → stop, keep `session.json`, the next whenFree run resumes with
`Content-Range: bytes */total`; the same after a network error, a 5xx, a restart of irdash or the PC (back-off 2, 4, 8
… 300 s); `404`/`410` on the session URL → start the upload again from zero; `401` → refresh once, then `signin`;
`403` with `quotaExceeded`/`uploadLimitExceeded` → kind `failed`, error "YouTube says today's upload limit is reached.
I'll try again after 9 in the morning" and a retry at 09:00 local (midnight Pacific is 08:00/09:00 UK); no internet
(`WebException` name resolution / connect failure) → error "No internet, waiting" and a retry in 60 s, no limit. Done
(`200`/`201` with the video JSON) → `GET /youtube/v3/videos?part=status&id=` and record the REAL `privacyStatus` and
`uploadStatus` (kind `shared`, `privacy` from the answer, `url` `https://youtu.be/<id>`); then
`POST /youtube/v3/thumbnails/set?videoId=` with the JPEG (a `403` means "skip, tell once" in the log). Only after the
read-back is the race `shared` (W1-1's free-up-space trusts that word).

**Settings** (irdash.ini, section `[youtube]`): `privacy=private|public` (default `private`; PLAN §4.3: private until
the first checked upload, then Peter's choice) and `template=1..5`; `YouTube.SetPrivacy`, `YouTube.SetTemplate`.

**Read side for the other cards:** `YouTube.StateJson(string raceId)` → the `state` object of `/api/library`
(`{"kind":"shared","pct":100,"privacy":"private","url":"https://youtu.be/…"}` / `{"kind":"sharing","pct":41}` /
`{"kind":"failed","error":"…"}` / `{"kind":"signin","error":"Sign in to YouTube again"}` / `{"kind":"offline","error":"No internet, waiting"}`
/ `{"kind":"none"}`) and `YouTube.Json()` → `{"signedIn":true,"privacy":"private","template":1,"queue":2}`. The lead sets
`Library.ShareState = YouTube.StateJson; Library.YouTubeJson = YouTube.Json;` at merge. Call
`StateBuilder.BumpLists(false, false, true, false)` whenever a state changes (that is how pages learn without polling).

**Testability:** every Google URL is a public static (`AuthUrl`, `TokenUrl`, `UploadUrl`, `ApiUrl`) the test points at
its pretend server; `YouTube.Dir` (default `dash\yt`) likewise; `YouTube.OpenBrowser` is a `Action<string>` the test
replaces (it "visits" the URL itself and posts the code back to the listener). Chunk size is a static too, so the
test uploads a 3 MiB fixture in 1 MiB chunks.

## Tests — `tests\youtube-test.ps1` + `tests\youtube-main.cs` + `tests\youtube-google.cs` (pretend Google)
Pattern: `tests\recorder-owner-test.ps1` (compile the `$src` list from `dash\build.ps1` with the test files, run,
print ok/FAIL). The pretend Google is an `HttpListener` on a free 127.0.0.1 port: `/o/oauth2/v2/auth` (records the PKCE
challenge, redirects with `code`), `/token` (checks the verifier against the challenge, answers tokens; a flag makes
it answer `invalid_grant`), the resumable `videos` endpoint (session URL; checks `Content-Range`; a flag closes the
connection once at 40 % of the bytes; answers `308` + `Range` on `*/total`; `404` after a flag; `403 quotaExceeded`
after a flag), `videos?part=status` (answers `private`), `thumbnails/set` (`403` once). Cases:
1. sign-in: the verifier matches the challenge, `token.bin` exists and is NOT plaintext (the file does not contain the
   refresh token string), the browser got one "signed in" page, the listener is closed.
2. refresh: an expired access token is refreshed before the upload; `invalid_grant` → `token.bin` gone, state `signin`
   with the exact message.
3. upload: 3 MiB in 1 MiB chunks, cut at 40 % → resumed from the `Range` byte, the file arrives byte-exact (hash),
   read-back `private`, `uploads.json` kind `shared` with the url, `StateJson` as in the contract, `pct` reached 100.
4. never twice: `Enqueue` on a `shared` race → false, "Already on YouTube"; on a `failed` one → true.
5. restart: kill the upload mid-way (stop the pretend server, make a fresh `YouTube` state from disk as a new process
   would), start the server again → `*/total`, finishes with no bytes re-sent before the `Range` byte.
6. yield: `Jobs.SessionOn` true after the first chunk → the job stops within one chunk and leaves `session.json`;
   false again → it finishes.
7. quota `403` → kind `failed`, the exact message, a retry time at 09:00 local; no internet → kind `offline`,
   "No internet, waiting".
8. thumbnail `403` → the upload is still `shared`, one log line, no exception.
9. nothing secret in the log: the test's log text contains neither the pretend client secret nor any token string.
`tests\jobs-test.ps1` still passes.
