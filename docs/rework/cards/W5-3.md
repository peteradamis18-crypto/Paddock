## What to build
1. **NVML** (`dash/src/nvml.cs`, new; P/Invoke of `C:\Windows\System32\nvml.dll`, which exists on this PC; no library):
   `nvmlInit_v2`, `nvmlShutdown`, `nvmlDeviceGetHandleByIndex_v2(0)`, `nvmlDeviceGetUtilizationRates` (gpu %, memory %),
   `nvmlDeviceGetClockInfo` (graphics = 0, and memory = 2), `nvmlDeviceGetTemperature` (sensor 0), `nvmlDeviceGetMemoryInfo`
   (used / total), `nvmlDeviceGetPowerUsage` (mW), `nvmlDeviceGetCurrentClocksThrottleReasons` (bit mask: 0x1 idle, 0x2
   applications clocks, 0x4 software power cap, 0x8 hardware slowdown, 0x20 software thermal, 0x40 hardware thermal, 0x80
   power brake). One `Nvml.Read()` returning a struct or null; init once, lazily, on the black box thread; every failure
   (no dll, no device, any non-zero return) = null, logged once, never thrown, never retried more than once a minute. Cost: one
   read per row (1 Hz; 10 Hz in fast mode) stays under the v1 ceiling (blackbox-test measures: under 1 % of a core at BelowNormal).
2. **Columns:** fill the four empty ones (`gpuLoad gpuClock gpuTemp gpuThrottle`, `blackbox.cs:309`; throttle as the short
   words "thermal" / "power" / "hw" / "" from the mask) and add `vramMb vramTotalMb ramFreeMb gpuPowerW diskReadMs`
   (`PerformanceCounter LogicalDisk "Avg. Disk sec/Read"`, max of the drives, next to the write one, `OpenCounters :193`;
   `Memory\Available MBytes` for RAM). The header line says `#v2`; every reader (`FreezeNear`, `Sentence`, perf's own
   reading, the tests) accepts v1 files (missing columns = empty) and v2 files. File size per race stays about 4 MB or less.

   (`dash/src/field.cs`; find the entry point, one line), counted as "ours" (`Ours :339`) like scan and save.
4. **`BlackBox.Running` from RigState** (`perf.cs:63`, the comment says so): `RigState.SimRunning || RigState.SessionOn`.
5. **Cause rules** (`BlackBox.Cause :478`), inserted BEFORE today's rule 5 "inside the sim", in this order after rule 4:
   (4b) throttle word set in the dip second → "the graphics card slowed itself down (N °C, <thermal|power limit|hardware>)";
   (4c) `diskReadMs` > 50 in the dip second → "the disk (reads took N ms)"; (4d) `vramMb` ≥ 95 % of `vramTotalMb` →
   "graphics memory full (N of M GB)". Plain words, one clause, under 70 characters. The 12 Nov verdict is unchanged
   (no black box file for it).
