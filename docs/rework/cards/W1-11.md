## What to build (per race, automatic, as part of SHARE TO YOUTUBE; nothing new for Peter to press)
1. **Title** (from facts, no model): the race's hook in Peter's voice, e.g. "P15 to P4 at Road Atlanta · GR86 · 1:34.850",
   "Last to P7 in the rain · Spa · Cayman GT4", "Pole and the win · Monza"; the rule table in `cuts.cs` extended from the
   REVIEW story (positions gained, podium, pole, fastest lap, an incident recovery, a last-lap pass from the field log). Keep
   the five templates as fallbacks; the picker on RACES still works.
2. **Description** (from facts): 3 short paragraphs: what happened (positions, the decisive lap from the field log), the car and
   track with the lap time and the iRating change, then the chapters (already made) and a fixed sign-off line Peter writes
   once in `dash\irdash.ini` (`youtube_signoff=`; empty = none). Tags: track, car, series, "iRacing", "sim racing".
3. **Thumbnail** (from the race's own picture, no stock art, no drawings; `premium: real assets only`): the frame at the race's
   best moment (the decisive pass from the field log, else the finish line, else the start) pulled with ffmpeg from the race
   video, 1280 x 720, with big broadcast type in the house gold: the position change ("P15 → P4") or the result ("WIN"), the
   track name small, Paddock's wordmark small; one layout, `System.Drawing`, the shell's fonts. Saved beside the video as
   `<race>.thumb.jpg`; set on the upload when the channel allows it, else kept for Peter to drag.
4. **Highlights clip** ("slice clips"): the recorder's existing cuts (the start, every pass involving Peter, incidents, the best
   lap, the last lap) concatenated with ffmpeg into `<race>.highlights.mp4` (≤ 3 minutes, hard cuts, no music, no transitions),
   made after the race in the same whenFree job as the thumbnail, never while a session is on. Shown as a second card under the
   race on RACES ("HIGHLIGHTS · 2:41") with its own SHARE; the full race stays the default upload.
5. **The model hook** (off by default): one function `Words.Improve(facts, draft)` behind `dash\irdash.ini` `youtube_words=templates|claude`;
   with `claude` and a key file `dash\yt\claude-key.txt` present (never in git, never logged), it asks the Claude API
   (`claude-sonnet-5-5`, one call per race, ≤ 400 output tokens, a fixed prompt in `docs/youtube-words.md` that forbids clickbait
   lies and keeps the facts) to rewrite title and description; on any failure the templates stand. The cost per race is written
   in `docs/USER-GUIDE.md` so Peter can decide. Do not build the key file; do not call the API in tests (a stub answers).
