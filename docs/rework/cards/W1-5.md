## What the screen does today (keep what works)
`Races` is a `Screen` (base class ~line 100: `build()` returns tiles `{c, r, w, h, text, sub, act, arg, style, wrap, once,
paint}`, `relayout()`, `switchTo('RigRaces')`, `cmd()`, `get()`, `say()`, `keyTick(sum)` from `/deck/summary`'s `races`
part every 5 s while on MAIN, `poll()` every 1.5 s while open). 24 text-only keys per page, one race per key, a second
screen per race with SHARE (opens YouTube's page — gone now) / DELETE (press again) / WATCH / KEEP, EXIT at 7,3.

## What to build
**Data:** `/deck/summary`'s `races` part is now `Library.DeckJson()` (W1-1): `{storage:{usedGb, freeGb, trashGb, moreRaces,
lowSpace}, races:[{id, track, car, type, isRace, startMs, sec, laps, best, mb, kept, thumb, state:{kind, pct, privacy, url, error}}]}`
(40 newest). While open, `poll()` reads `/api/library` (the full list, same names plus `trash`) at the 1.5 s interval
only while something is in flight (a `sharing` race or a toast), else every 5 s — request-rate ceiling for the deck is
0.3/s idle (W0-5 test), so do not add a poller.
**Thumbnails on keys:** `fetch('/api/library/thumb?id=…&w=144')` → `blob` → `createImageBitmap` → `drawImage` onto the
key canvas, cached per id in a `Map` (fetched once per id, re-fetched only when `thumb` flips from false to true);
while loading or when `thumb` is false: a dark key with the track's first word in gold (never an empty black key). The
`paint` hook on a tile already lets a screen draw its own picture (the Confirm YES uses it).
**List view (pages of 6 cards; "27 empty keys" never again — a page shows only the cards it has, no padding):**
- rows 0–1, columns 0–5: card n = two keys side by side: left = the picture (press = open the race), right = the name
  key: track (20 px or larger, at most 8 characters per line, wrap 2), `sub` = date · length (`raceWhen`, "21 MIN"), a
  gold corner when `kept`, a one-word state in the colour-by-job rule (gold "SHARING 41%" / green "ON YT" / red the
  error's first word / grey nothing); press the name = tick / untick (gold frame on both keys).
- (6,0) NEWER ◀ and (7,0) OLDER ▶ (only when there is a page that way), (6,1) RACES ONLY / ALL SESSIONS, (7,1) the
  storage key "283 GB · FREE" with `lowSpace` in amber ("LOW · FREE UP" → `racefree`).
- row 2: the message line (`say`), else "N TICKED" when any, else the hint "PICTURE OPENS · NAME TICKS" (grey, small).
- row 3: with ticks: SHARE SELECTED (cols 0–1, gold, `raceshare a=id|id`), DELETE SELECTED (2–3, red, `racetrash`),
  SELECT ALL SHARED (4, grey), CLEAR TICKS (5, grey); without ticks: nothing but the hint; EXIT at (7,3) always, red,
  the same word as every screen.
- DELETE SELECTED → the cards leave at once and (4–6, row 2) shows "DELETED 3 · UNDO" for 8 s (press = `raceundo
  a=<batch>` from the command's answer); no press-again anywhere (W0-1 took the x2 path out of the deck for good).
**Open view (a picture pressed):** the thumbnail across a 4×2 block (cols 0–3, rows 0–1, one `paint` over the four
tiles, as the intro's big picture does), facts keys at (4..7, 0) track/car · date · length/laps · best, (4..7, 1) the
state line across four keys in its colour ("ON YOUTUBE (PRIVATE)", "SHARING 41%", "NOT SHARED", "SIGN IN TO YOUTUBE"
→ press = `ytsignin`); row 2: SHARE (gold, `raceshare a=id`; grey "ON YOUTUBE" when shared), DELETE (red, `racetrash`,
then the UNDO key), WATCH (green, `racewatch`), KEEP / KEPT (`recsave`), and a 2-wide key with the short link
`youtu.be/…` when shared (irdash has no clipboard command; the page has COPY LINK, the deck only shows it); row 3:
BACK (0,3), EXIT (7,3).
**Every key has a word; nothing blinks; the deck never switches by itself** (MY DRIVE rule, W0-1). Opening the screen
still goes through `switchTo('RigRaces')`; the profile page `RigRaces` has 32 tiles already.
