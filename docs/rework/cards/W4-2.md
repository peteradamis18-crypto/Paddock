## `Chart` (ES module, canvas, no library)
- `Chart.mount(el, { x: { len, unit: 'm' }, rows: [{ key:'delta', label:'DELTA', unit:'s', kind:'line', series:[{ label:'this lap', color:'gold', data: Float32Array }] },
  { key:'speed', label:'SPEED', unit:'mph'|'km/h', series:[…two…] }, { key:'pedals', series:[throttle, brake] }, { key:'steer' }, { key:'gear', kind:'step' }],
  corners: [{ n, label, p0, pa, p1 }], readout: el2 })` draws the stack on ONE distance axis (1 m grid), the delta row
  first in gold (the one that tells him where to look), speed/pedals/steering/gear below, corner bands and labels along
  the top; the cursor is one vertical line across every row; the readout column (`readout` element) always shows the
  cursor's values in 32 px (`--t-read`) for every row and both laps — no mouse-only tooltips anywhere.
- `Chart.setCursor(m)`, `Chart.setRange(a, b)` (zoom to metres; `Chart.zoomCorner(n)`, `Chart.zoomLap()`), `Chart.onCursor(fn)`,
  `Chart.update(rows)` (new data, same layout), `Chart.unmount()`. Wheel zooms around the cursor; drag moves the cursor;
  the deck's zoom arrives through the page (`wb-*` commands → `Chart.zoomCorner/zoomLap/setCursor`).
- Drawing under 4 ms a frame at 1920 wide for 6 rows × 2 laps × 4000 points (measure); redraw only on change; nothing
  while hidden. Colours only from design tokens (this lap `--gold`, the reference `--ink`, gains `--gain`, losses `--loss`).
- Reads the PWB1 format of `/api/review/traces` through one helper `Chart.fromPwb(arrayBuffer) → rows` (the header and
  Float32 arrays as `/analysis/channels` writes them today; see workbench.js for the parse).

## `Map` (ES module around `v2/map.js`'s `TrackMap`)
- `Map.mount(el, { key, id, size })` draws the outline (from `/trackmap?key&id`, else iRacing's own drawing from
  `data/iracing-maps` by track id, as `v2/map.js` already does) once, offscreen; `Map.colour(gain)` colours the outline per
  lap percent (gain array: + `--gain`, − `--loss`, 0 `--ink`); `Map.marks([{ n, p }])` puts the numbered marks 1, 2, 3;
  `Map.cursor(p)` moves one dot; `Map.cars([{ p, me }])` for the race story's positions; `Map.unmount()`. No polling: one
  fetch at mount, one retry after 5 s if the outline is missing, then a plain "map not available" word.
