# Paddock privacy

Paddock is one person's sim-racing software. It runs on that person's own PC and nowhere else.

- It does not collect, send or sell any personal data. There is no server, no account and no analytics.
- Its YouTube sign-in is used only to upload that person's own race videos to their own YouTube channel, with the
  "upload" permission only. The sign-in token stays in a file on that PC and is never sent anywhere but Google.
- Nothing is shared with anyone. Deleting the folder removes everything.

Questions: open an issue on this repository.
